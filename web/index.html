How it works

  1. A random forest is trained on a synthetic tabular dataset (10 features, 5 informative). Its accuracy on held-out data is the reference.
  2. The stream is cut into windows of 1,000 requests. Each window is compared with the reference data.
  3. Three checks run on every window: a KS test per feature, a classifier that tries to separate old from new rows, and a KS test on the model's predicted probabilities.
  4. The combined system alerts only when the input changed and either an important feature moved or the predictions moved, and only if that holds in two windows in a row.
  5. True labels are hidden for 3 windows, to copy the delay of real production systems.
